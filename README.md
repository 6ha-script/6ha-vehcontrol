## 📋 الوصف
نظام متطور ومتكامل للتحكم بالمركبات في FiveM مع واجهة احترافية وسهلة الاستخدام.

## ✨ المميزات

### 🚗 التحكم الكامل بالمركبة
- **المحرك**: تشغيل وإيقاف المحرك
- **الأبواب**: التحكم بجميع أبواب المركبة
- **النوافذ**: فتح وإغلاق جميع النوافذ
- **المقاعد**: الانتقال بين مقاعد المركبة
- **الإضاءة**: التحكم بالإضاءة الداخلية
- **الإشارات**: إشارات يمين، يسار، وطوارئ
- **الصندوق**: فتح وإغلاق الصندوق الخلفي
- **غطاء المحرك**: التحكم بغطاء المحرك

### 🎨 واجهة مستخدم احترافية
- تصميم عصري وأنيق
- ألوان بنفسجية مميزة
- تأثيرات بصرية سلسة
- رموز واضحة وسهلة الفهم
- دعم كامل للغة العربية

### ⚙️ إعدادات قابلة للتخصيص
- تخصيص الأوامر
- التحكم بالأصوات
- إشعارات قابلة للتعديل

## 📦 التثبيت

### 1. تحميل الملفات
```bash
6ha-vehcontrol/
├── client/
│   └── main.lua
├── server/
│   └── main.lua
├── html/
│   ├── index.html
│   ├── script.js
│   ├── style.css
│   └── images/
│       └── (ضع الصور هنا)
├── config.lua
└── fxmanifest.lua
```

### 2. إضافة السكربت
1. ضع مجلد `6ha-vehcontrol` في مجلد `resources`
2. أضف السطر التالي إلى ملف `server.cfg`:
```cfg
ensure 6ha-vehcontrol
```

### 3. إعادة تشغيل السيرفر
```bash
restart 6ha-vehcontrol
```

## 🎮 الاستخدام

## ⚙️ الإعدادات

### config.lua
```lua
-- الأمر لفتح الواجهة
Config.Command = 'vehcontrol'

-- إعدادات الصوت
Config.Sounds = {
    Enable = true,      -- تفعيل/تعطيل الأصوات
    Volume = 0.3        -- مستوى الصوت
}
```
